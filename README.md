## Установка и запуск окружения.

#### Linux / macOS:
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

#### Windows (CMD):
```cmd
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```
